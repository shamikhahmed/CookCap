# Recipe hero photos

Drop files here as:

- `<recipe-id>.webp` — full hero
- `<recipe-id>@sm.webp` — ~800w thumb

Id = kebab-case from the recipe object / URL (e.g. `karahi-chicken`).

Free stock already fills most slots; your photos override when present.

See **docs/photos.md** for blur regen (`node scripts/fetch-images.mjs`) and how to find ids.
