CookCap Support

Need help with the book, cook mode, shopping list, or installing the PWA? We’re here.

Contact

  • Portfolio / support hub: shamikhahmed.github.io/support.html
  • Bug reports: GitHub Issues

Common topics

  • Lost data: Export / merge backup from About before switching phones. Data is local-only (IndexedDB).
  • Offline: After the first visit the service worker caches the shell and recipe assets. Hard refresh once after updates.
  • Book name: First-run dresser sets {Name} Cooks. Appearance and theme live under the Appearance control.
  • Cook mode: Open a recipe → Start cooking. Exit anytime. Lenses (My Plate, Mother, …) are optional.
  • Guest PIN: Optional lock in About for shared devices.
  • Nutrition: Values are estimates, not medical advice.

Response time

We aim to reply within 2 business days.
