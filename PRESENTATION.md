# CookCap — Presentation

**v2.2.5** · https://shamikhahmed.github.io/CookCap/

## Pitch

CookCap opens like a hardcover. Name the book (Dresser ceremony, or calm Simple path). Flip offline. Optional lenses for goals, family cooking, budget — never required.

## Demo

1. First-run → Begin → name → optional profile/mode → cover embossed `{Name} Cooks`
2. (Optional) My Plate / Mother / Budget from Mode
3. Flip → For You / fit badge → Log this → Calendar
4. Appearance (palette) → skins / cloth tabs / Flip vs Fast
5. ··· → Reader restores pure book
