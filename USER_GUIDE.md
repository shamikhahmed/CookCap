# CookCap — User guide

## Open

https://shamikhahmed.github.io/CookCap/

1. Enter your name → cover becomes **YourName Cooks**.
2. Optional: add who eats from the book + pick a mode (or skip → Reader).
3. Flip / Tabs. Phone: **Tabs** in footer.

## Modes (··· → Mode)

- **Reader** — pure book, no tracking chrome.
- **My Plate** — fit badges, For You shelf, log meals, make-it-healthier.
- **Mother** — cooking for selected eaters; allergen flags.
- **Budget** — cost estimates + weekly grocery budget + pantry.
- Others (Quick, Beginner, Dawat, Ramadan, Toddler, health lenses, Couple) re-rank recipes.

## Profiles / Calendar / Pantry

··· → Profiles · Calendar · Pantry & budget.

Log from a recipe with **Log this**. Calendar shows planned vs eaten. Pantry matches what you can cook now.

## Honesty

Macros and costs are **estimates** unless marked verified. Health modes are **not medical advice**.

## Tips

Install to home screen for offline. ··· → Change book name. Clearing site data wipes local favorites / shopping / profiles / diary on that device.
