# CookCap — A Family Cookbook

Cap-family offline-first cookbook PWA. Name your book → **`{Name} Cooks`**.

**Live:** https://shamikhahmed.github.io/CookCap/

## Stack

Next.js 15 (`output: 'export'`) · React 19 · Tailwind v4 · Motion · IndexedDB · SW `cookcap-v2`

## Run

```bash
npm install && npm run dev
npm run build          # → out/
npm run pages:build    # with /CookCap basePath
npm run gallery
```

## Recent fixes (1.5.1)

- Photos work on GitHub Pages (`withBase`)
- Mobile full-bleed reader (no overlapping edge/rail)
- Flip touch improved
